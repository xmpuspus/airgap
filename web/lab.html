      04 / REPRODUCE THE RUN

      Take the evidence with you

      The kit builds the site, executes the replay and model experiment, drives the real browser journey, and exports five browser recordings. Raw captures stay local under tmp/recordings. 

      npm run public:demo -- --model /path/to/gemma-3.gguf

      Requires Node 22.18 or newer, Python 3, Playwright 1.58.0, Chromium, FFmpeg and a local model. No API key is used.

      Service snapshots are text extracted from fetched public pages; their hashes identify saved extracts. Historical source hashes identify the archived government PDFs, with separate OCR text and page references. Re-fetch and review before relying on a source that needs a new check.
